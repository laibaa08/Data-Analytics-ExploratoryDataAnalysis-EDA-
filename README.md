This project focuses on predicting passenger survival on the Titanic using Logistic Regression. The dataset is preprocessed by handling missing values (median imputation for Age and Fare, mode imputation for Embarked), removing irrelevant columns such as Name, Ticket, Cabin, and PassengerId, and encoding categorical features like Sex and Embarked into numeric values. Features are standardized using StandardScaler to improve model performance. The Logistic Regression model is trained on the cleaned dataset with an 80-20 train-test split, and evaluated using accuracy, confusion matrix, and classification report to assess precision, recall, and F1-scores. Feature importance is derived from model coefficients and visualized to highlight influential predictors such as Sex, Pclass, and Fare. Predictions are saved to an output file (titanic_predictions.csv) for reproducibility, and visualizations provide insights into how different factors contributed to survival. This project demonstrates the complete pipeline of preprocessing, training, evaluation, and result interpretation in a classification task.
